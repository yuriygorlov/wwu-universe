# Размещение WWU

## Обычный хостинг

1. Скачайте проект из репозитория или распакуйте архив.
2. Загрузите `index.html` и всю папку `assets` в каталог сайта.
3. Проверьте, что `index.html` доступен по адресу сайта, а `assets/app.js`, `assets/model.js` и остальные файлы возвращаются без ошибок.
4. На телевизоре откройте адрес сайта с параметром `?tv=1`.

Пример формата адреса: `https://ваш-домен/?tv=1`. Домен необходимо настроить отдельно; проект сам ничего не публикует.

Все ссылки на ресурсы относительные, поэтому проект можно разместить и в подпапке, например `https://ваш-домен/wwu/?tv=1`.

Нужна раздача обычных HTML, CSS и JavaScript. Команда сборки не требуется. Корень публикуемого каталога — каталог с `index.html`.

## Просмотр в локальной сети

На компьютере в каталоге проекта:

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

На телевизоре в той же локальной сети откройте `http://IP-КОМПЬЮТЕРА:8080/?tv=1`, подставив LAN-адрес компьютера. `localhost` на телевизоре указывает на сам телевизор, а не на компьютер.

Компьютер должен оставаться включённым; сервер должен быть доступен из локальной сети. Для постоянного размещения используйте штатный веб-сервер или статический хостинг.

## GitHub Pages

Если GitHub Pages доступен для выбранного репозитория и тарифного плана, выберите в его настройках Pages публикацию из ветки `main`, каталог `/ (root)`. Файл `.nojekyll` уже включён. Адрес страницы появится после публикации в настройках репозитория; допишите к нему `?tv=1`.

Создание репозитория само по себе не включает Pages и не публикует сайт.

## Проверка на телевизоре

- Открывается сфера и подписи направлений.
- Стрелки вращают модель; OK открывает меню; Back закрывает его.
- В меню можно выбрать направление и пересечение.
- Работают масштаб и остановка автовращения.
- Кнопка полного экрана либо включает его, либо показывает доступный способ через меню браузера.

Если браузер телевизора не передаёт события пульта странице, используйте режим указателя, подключённую мышь или клавиатуру. Старый браузер без современных Canvas и JavaScript может потребовать обновления или внешней приставки.
