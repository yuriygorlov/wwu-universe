# WWU · WEBA WORLD UNIVERSE

Интерактивная трёхмерная карта исследований и направлений применения WWU. В центре находится «Наука», внутренний слой содержит исследовательские темы, внешний слой показывает направления и их пересечения.

## Быстрый запуск

Откройте `index.html` в браузере. Проект также можно запустить через простой статический сервер:

```sh
python3 -m http.server 8080
```

Обычный режим: `http://localhost:8080/`.

Режим телевизора: `http://localhost:8080/?tv=1`.

Сборка, Node.js, API, база данных и внешние CDN не нужны. Библиотека D3 и геометрия карты находятся в проекте. После загрузки страницы приложение не запрашивает данные из интернета.

## Управление

| Действие | Компьютер / телефон | Телевизор или клавиатура |
|---|---|---|
| Вращение | Перетаскивание мышью или пальцем | Стрелки, когда меню закрыто |
| Масштаб | Колесо мыши, щипок, кнопки + / − | Кнопки + / − в меню |
| Выбор направления | Узел или список «Направление» | OK, затем список «Направление» |
| Выбор связи | Линия или список «Пересечение» | Список «Пересечение» в меню |
| Переход по меню | Tab / Shift+Tab, мышь | В списке ↑ ↓ меняют выбор; ← → переходят к соседнему элементу |
| Закрыть меню | «К модели» или Escape | Back / Return |
| Автовращение | Кнопка «Автовращение» | Та же кнопка в меню, пробел на клавиатуре |
| Полный экран | Кнопка «Полный экран» | Та же кнопка в меню, F на клавиатуре |
| Исходный ракурс | «Общий вид» | «Общий вид» в меню |

В режиме ТВ автоповорот включается при загрузке, если пользователь не запросил уменьшение анимации в настройках устройства. Ручное управление и выбор направления останавливают автоповорот.

Полный экран включается нажатием кнопки: браузеры требуют действия пользователя. Если API полного экрана отсутствует, доступен режим ТВ; панель браузера можно скрыть его собственными средствами, если такая функция есть.

Используются стандартные события клавиатуры, а также коды Back `10009` и `461`. Доставка этих событий веб-странице зависит от браузера телевизора. Управление проверяется в браузере; совместимость с конкретной моделью ТВ нужно проверить на самом устройстве. Это веб-страница, а не установленное приложение Tizen или webOS.

## Состав проекта

```text
index.html                 Страница приложения
assets/app.css             Обычный режим и режим ТВ
assets/app.js              3D-геометрия, отрисовка и управление
assets/model.js            Направления, описания и смысловые связи
assets/world-land.js       Геометрия суши Natural Earth
assets/vendor/d3.min.js     D3 7.9.0
assets/vendor/LICENSE-d3.txt
DEPLOY.md                  Размещение на хостинге
THIRD_PARTY_NOTICES.md      Источники и сторонние лицензии
```

Для изменения названий, описаний и пересечений редактируйте `assets/model.js`. `id` узла должен быть уникальным; связи ссылаются на `id`. При добавлении узла добавьте соответствующую позицию в `researchPlaces` или `businessPlaces`.

Карта концептуальная: координаты узлов не обозначают расположение компаний, численные веса и подтверждённую силу связей. «Эфир» оставлен среди гипотез без назначенных прикладных результатов.
